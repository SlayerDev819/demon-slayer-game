📖 О проекте

Demon Slayer — это текстовая RPG, которую я создаю сам. В игре есть прокачка, бои, магия, боссы и сюжет. Скачивай, играй и становись легендой!

🔥 В игре есть:

  • ⚔️ Боевая система
  • 📈 Прокачка и уровни
  • 🛡️ Защита и зелья
  • 🐉 Боссы с фазами
  • 🏙️ Магазин
  • 🧠 Навыки (сила, ловкость, интеллект)

📖 Инструкция по установке и запуску

📥 Шаг 1. Скачай файл игры

Нажми на кнопку «Скачать игру» на главной странице.

Файл скачается в папку Downloads (Загрузки) на твоём телефоне.

📦 Шаг 2. Установи Termux

Termux — это приложение, в котором мы будем запускать игру.

  • ✅ F-Droid (рекомендуется): тык сюда
  • ✅ GitHub: тык сюда

⚠️ Не скачивайте Termux из Google Play — там старая версия!

🐍 Шаг 3. Установи Python

pkg update && pkg upgrade -y
pkg install python -y

📂 Шаг 4. Перемести файл игры

cd ~/storage/downloads
ls

▶️ Шаг 5. Запусти игру

python demon_slayer_v3.py
