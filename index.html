📖 Как установить и играть

📥 Шаг 1. Нажми «Скачать игру» — файл сохранится на телефон.
📦 Шаг 2. Установи Termux (приложение для запуска игр).
Скачай с F-Droid (рекомендуется).
🐍 Шаг 3. Открой Termux и введи:
pkg update && pkg upgrade -y
pkg install python -y
📂 Шаг 4. Перемести скачанный файл в папку ~/storage/downloads.
В Termux: cd ~/storage/downloads
▶️ Шаг 5. Запусти игру:
python demon_slayer_v1.py
