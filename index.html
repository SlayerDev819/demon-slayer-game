📖 Подробная инструкция по установке и запуску

📥 Шаг 1. Скачай файл игры

Нажми на кнопку «Скачать» в разделе «Части игры».

Файл скачается в папку Downloads (Загрузки) на твоём телефоне.

Файл будет называться: demon_slayer_v1.py (или v2, v3).

📦 Шаг 2. Установи Termux

Termux — это приложение, в котором мы будем запускать игру.

Где скачать (безопасно):

  • ✅ F-Droid (рекомендуется): тык сюда
  • ✅ GitHub: тык сюда

⚠️ Не скачивайте Termux из Google Play — там старая версия!

🐍 Шаг 3. Установи Python

Открой Termux и введи команды по очереди (нажимай Enter после каждой):

pkg update && pkg upgrade -y
pkg install python -y

Это установит Python — язык, на котором написана игра.

📂 Шаг 4. Перемести файл игры

Скачанный файл demon_slayer_v1.py лежит в папке Downloads.

Введи в Termux команду, чтобы перейти в эту папку:

cd ~/storage/downloads

Теперь ты внутри папки Downloads. Проверь, есть ли файл:

ls

Ты должен увидеть demon_slayer_v1.py (или ту версию, которую скачал).

▶️ Шаг 5. Запусти игру

Введи команду, чтобы запустить игру:

python demon_slayer_v1.py

Игра начнётся! 🎮

Если у тебя другая версия — замени v1 на v2 или v3.

🔄 Как обновить игру

Если вышла новая версия, просто скачай новый файл и замени старый.

Повтори шаги 1, 4 и 5.

❌ Что делать, если игра не запускается

  • ➡️ Проверь, что ты в папке ~/storage/downloads
  • ➡️ Проверь, что файл называется точно demon_slayer_v1.py
  • ➡️ Проверь, что установлен Python (pkg install python -y)
  • ➡️ Если ошибка — напиши автору игры
